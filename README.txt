MY FIRST WEBSITE — DEPLOYMENT PRACTICE

Files:
- index.html: website structure and content
- style.css: website appearance and responsive layout
- app.js: button interaction

RUN LOCALLY
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
4. Click "Click to say hello" to test the JavaScript.

DEPLOY WITH GITHUB PAGES
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository, for example: my-first-website
3. Upload index.html, style.css, and app.js to the repository's root.
4. In the repository, open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then save.
7. Wait for the deployment to finish. GitHub will show your public website URL in Settings -> Pages.

This is a static website. It does not need Node.js, a backend, a database, or API keys.
